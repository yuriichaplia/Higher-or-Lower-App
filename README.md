# Higher or Lower Game in Python Flask<br>
This is a simple Python Flask web application where the computer chooses a random number between 0 and 9 and you try to guess it. If your guess is incorrect the app gives hints such as `Too low ` or `Too high`.<br>

### Note that there are no fields on the webpage for your guess to be provided. Instead, you should provide your guess in the address bar by adding `/your_guess` to it.<br>
